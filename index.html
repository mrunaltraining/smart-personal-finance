Help & User Guide

Quick Start Guide
  1. Primary Accounts — Add a Primary (Expenditure) + Salary account to unlock all tabs
  2. Optional Accounts — Optionally add Saving & Investment accounts
  3. Outflow — Add ALL fixed deductions (EMIs, rent, insurance, savings, investments)
  4. Budget — Enter Primary Income → Review breakdown → Execute Transfer
  5. Mid-month — Quick Update: enter current expenditure balance + CC spending
  6. Month end — Close Month → carries balance forward
Important: Add all outflow items before Execute Transfer. Items added afterwards will not be deducted from salary.
Network Status Indicator

The network status indicator appears in the user bar (next to your email) and shows the Firebase save status.

Status States

Green checkmark with circleData saved successfully (auto-hides after 2 seconds)
Yellow refresh arrows (blinking)Retrying save due to network issue (stays visible)
Red circle with exclamationSave failed (stays visible)
Red WiFi with slashBrowser is offline (stays visible)
Red triangle alertQuota exceeded (stays visible)
Yellow refresh arrows with slashReconnecting (stays visible)

Interaction

Desktop: Hover over the icon to see detailed status text

Mobile: Tap the icon to see details (icon only shown for space efficiency)

Auto-Hide Behavior

Success state (green checkmark) automatically hides after 2 seconds. Warning and error states stay visible until resolved.

Variable Expenditure Formula 
Variable Expenditure = totalFunded − current exp balance

Where:

totalFunded = carry forward + salary leftover + pre-existing balance

This snapshot (_initialBalance) is captured at Execute Transfer and doesn't change during the month.

Financial Goals

Goal Type Auto-Selection

The system automatically selects the goal type based on your target date:

Short Term≤ 1 year from today
Mid Term1-3 years from today
Long Term> 3 years from today

Default: Long Term if no target date is selected

Manual Override

You can manually change the goal type if needed. Once you manually change the type, the system will respect your choice and won't auto-select again for that goal.

Status Auto-Calculation

Status is automatically calculated based on progress and target date. You don't need to manually set it.

Planned: No progress yet

Ongoing: Progress started but not complete

Achieved: Goal fully funded

Missed: Target date passed without completion

Covered: Goal funded from other sources

Precautions

Before Transfer

  • Add ALL outflow items first — transfer uses items that exist at the moment
  • Verify Primary Income matches actual salary
  • Ensure Saving/Investment accounts exist if applicable

During Month

  • Update expenditure balance regularly via Quick Update
  • If outflows change after transfer → use Recalculate Transfer
  • Don't manually edit salary account balance

Month End

  • Always Close Month before starting next
  • Update exp balance before closing (affects carry forward)
  • Export backup monthly for safety

Data Safety

  • Always Export Backup before Reset All Data or Delete Account
  • Import overwrites ALL data — export current data first
Frequently Asked Questions
Q: I added outflows after Execute Transfer. What do I do?

A: A red "Transfer Mismatch Detected" banner will appear. Click Recalculate Transfer to fix.

Q: What is Variable Expenditure?

A: Auto-calculated as totalFunded − current exp balance. It tracks how much has left your expenditure account since transfer.

Q: Are One-Time items included in budget?

A: No. One-Time frequency items are excluded from auto-debit, pie charts, and Total Outflow. Tracked for reference only.

Q: How do I fix wrong data?

A: Export backup → edit the JSON → import the corrected file. For transfer issues, use the Recalculate button.

Q: What's the difference between Outflow and Insurance tabs?

A: Outflow = premium payments (auto-debited from salary). Insurance = policy details (coverage, nominees). Both should have matching entries for active policies.

Q: Can multiple users use this app?

A: Yes. Each user has their own account. Data is completely separate per user.
